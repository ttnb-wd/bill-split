# Bill Split

Run locally:  npm run dev   (Node 18+, no npm install needed)  -> http://localhost:3000

The calculator opens first. Use the top-right profile button to customize your name, color, emoji, or uploaded profile photo; group tabs are available from the bottom navigation. Create groups with a name, add people from groups saved in this browser, and invite others with the group link.

Deploy (so friends can open one link): upload this folder to Render / Railway / Fly.io as a Node web service.
Start command: npm start
Set the DATABASE_URL environment variable on the host (copy it from .env). Do NOT commit .env.
